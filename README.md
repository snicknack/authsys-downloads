# AuthSYS downloads

Installers for AuthSYS, the 3DIGIT account app. Download it from
[3digitsamples.com/pages/authsys](https://3digitsamples.com/pages/authsys).

This repository holds release files only. Each release carries the same three file names, so the
links on the website always fetch the newest one:

| Platform | File |
|---|---|
| Windows | `AuthSYS-Windows.exe` |
| macOS (Apple Silicon) | `AuthSYS-macOS-AppleSilicon.pkg` |
| macOS (Intel) | `AuthSYS-macOS-Intel.pkg` |
